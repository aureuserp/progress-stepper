# Reporting Security Issues

We value the contributions of the security research community and appreciate your efforts to help keep `aureuserp/progress-stepper` and its users secure.

## Where Should I Report Security Issues?

If you believe you have discovered a security vulnerability in this package, **please do not** use the public issue tracker and **do not** disclose it publicly.

Instead, you may report security issues through **either** of the following responsible disclosure channels:

- **Email:** Send detailed information to **support@webkul.com**

- **Security Advisory:** Report privately via GitHub's [Report a vulnerability](https://github.com/aureuserp/progress-stepper/security/advisories/new) workflow

Both channels ensure that security issues are reviewed promptly and handled responsibly before any public disclosure.

We appreciate your cooperation in helping us maintain a secure ecosystem for all users.
